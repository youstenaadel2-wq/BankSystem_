# 🏦 Bank Management System

📖 Overview
A console-based **Bank Management System** built with **Python** using **Object-Oriented Programming (OOP)** and **File Handling**.
The system simulates real banking operations including customer registration, account management, authentication, deposits, withdrawals, and transaction history.

## ✨ Features

- 👤 Create Customer
- 🏦 Create Account
- 🔐 Secure Login with PIN
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔍 Search for Accounts
- 🗑 Delete Accounts
- 📄 Display Customer Information
- 💾 Save Data into Text Files
- 📜 Transaction History
## 🛠 Technologies Used

- Python
- Object-Oriented Programming (OOP)
- File Handling
- Dictionaries
- Lists
